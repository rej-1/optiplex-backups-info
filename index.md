# Optiplex Backups

Optiplex Backups is a personal-use backup utility operated by the owner of the [rej-1 GitHub account](https://github.com/rej-1). It is not a public backup service and does not accept registrations.

The utility uses locally operated backup software and the Google Drive API to store encrypted, versioned backups in the operator's own Google Drive account. Google authorization permits the utility to create and manage its backup files and restore them when requested.

This public website contains application information only. It does not host backup files, credentials, encryption keys, or a Google sign-in form.

[Privacy policy](privacy.html)

For questions, contact the operator through the [project's issue tracker](https://github.com/rej-1/optiplex-backups-info/issues). Do not submit private data or credentials in public issues.
